# ProfessionarLARPERs

Small starter template for a hackathon project.

## Project Structure

```
.
├── public/      # Static assets
├── src/         # Application source code
├── tests/       # Project tests
├── .gitignore
└── README.md
```

## Quick Start

1. Pick your stack (Node.js, Python, etc.).
2. Add your app code inside `src/`.
3. Put static files in `public/`.
4. Add tests in `tests/`.
5. Update this README with setup and run commands for your chosen stack.

## Hackathon Checklist

- [ ] Define MVP scope
- [ ] Set up core app in `src/`
- [ ] Add at least one test in `tests/`
- [ ] Prepare demo assets in `public/`
- [ ] Add deployment/demo instructions
