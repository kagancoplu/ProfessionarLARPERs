- **Known issues / lessons (for everyone):**
  - The SDK makes everything after the top `OP_RETURN` **a single data chunk**. Do not parse the AgentCoop envelope by hand; use `parseOpReturn`.
  - `WalletClient` methods **do not take** an originator parameter (it is given in the constructor); a wallet-toolbox `Wallet` does.
