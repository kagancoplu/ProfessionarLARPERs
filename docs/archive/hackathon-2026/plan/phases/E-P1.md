## 2. Work items and files

### 2.1 Sprites (`assets/sprites/`)
`villager` (16×24; 3 outfit colours, one per profile: finetune/eval/inference; 2 directions × 2 walk frames + idle; the left direction mirrored), `house` (32×32, 2 roof colours), `workshop` (48×48, chimney), `chest` (16×16, closed/open), `cart` (32×20, horse + cart), `bell` (16×16, 2 frames), `tree` (16×24), `stall` (32×24), `gate` (24×32), `stranger` (ready for P3, 16×24). `tools/sprites.mjs` also produces **`public/game/ground.png`** (a tile strip: grass A, grass B, dirt, road) → the Phaser tileset.

### 2.2 Town (`src/town/`)
- `scenes/TownScene.ts`: `make.tilemap` (ground data generated by `map/ground.ts`: grass + a dirt square + a road from the gate to the square), buildings from the `map/town.json` object layer (`workshop`, `house` slots 1–3, `board`, `stall`, `gate`, the `harbor` spot), points (`square-centre`, `visitor-spawn`, `guard-post`). Camera: drag, wheel zoom 2×/3×/4× (integers), bounds. Night: a dark blue overlay (alpha 0.45) + window lights (yellow squares) when the theme is `night`. DOM container on (`dom.createContainer`) → labels and bubbles in HTML (Pixelify, crisp).
- `entities/Villager.ts`: sprite + name label (DOM) + purse (coin sprite, glows while "reserved") + bubble (DOM, 4 s); `walkTo(x,y,speed)` (tween, interruptible), `wander()` (random around waiting points), `face(dir)`.
- `entities/Board.ts`: board + sack (5 fill frames) + DOM label (name, `pledged/target`, "Festival in …") + hourglass (locking) + a floating "+N credits"; `fade()` (failed: the board fades, 1 px down), `settle()` sparkle.
- `entities/Workshop.ts`: workshop + sign ("H100 GPU-hour") + chimney smoke (particles while a job runs, `job_running`; stops on `job_done`).
- `entities/House.ts`: house + a chest in front (if the agent holds credits; it "drops" at settlement) + the owner's name.
- `entities/Cart.ts`: crosses the square left to right at settlement, leaves a chest at each house.
- `fx/queue.ts`: `FxQueue` — event → animation promise; **ordered**, interruptible, a `speed` multiplier (replay speed), `prefers-reduced-motion` → a short cut. A big scene (`settlement`) waits for the queue; small ones (bubbles) run in parallel.
- `fx/scenes.ts`: `pledgeFx`, `lockInFx`, `settlementFx` (bell ×3, cart, chests, gold from the purses to the workshop, scroll), `failedPoolFx` (the board fades, a "Nobody lost a satoshi" bubble), `thoughtFx`, `injectionFx` (P3 skeleton), `jobFx`.
- `bridge.ts`: subscribes to the store (agent added/removed → villager/house assignment; pool list → active board; theme) and the bus (event → `fx.enqueue`). Phaser fetches nothing; it writes only `ui` to the store (click → `openDrawer`).
- `TownCanvas.tsx`: React wrapper (lazy Phaser, `pixelated`, size `Scale.FIT` 960×540), with React corner counters and `TownDrawer` on top.
- `TownDrawer.tsx`: `ui.drawer` → pool detail (`PoolDetail`), agent card (`AgentCard`, decision log, "focus" camera), scroll (`TxScroll`: type, txid, WoC, actors).

### 2.3 Consoles (`src/consoles/`)
- `pools/PoolsPage.tsx`: filter (open/locking/settled/failed/cancelled), sort (deadline, fill, discount), card/table (progress, festival countdown `blocksToHuman(deadline − height)`, sats/credit vs retail + `demo pricing`), click a row → `PoolDetail` drawer (terms, the pledge table `usePledges`, `coordinator` round/blacklist/last round, offer present, settlement txid, audit link in live mode).
- `explorer`: type filter (T1–T11), actor, time; WoC links (exist). `metrics`: B's `/metrics` in live mode (`custodiedSats`, `custodyCheck`), derived in mock.
- `LiveFeed`: source filter (small), 50 → 100.

### 2.4 Replay (`src/replay/`)
- `tools/record-mock.mjs` (tsx): runs one scenario cycle synchronously and writes `public/replays/mock-demo.jsonl` (timestamps from the scenario offsets; `mock_` txids). Committed.
- `ReplayBar.tsx` (bottom bar, only in `mode === 'replay'`): play/pause, speed 0.5/1/2/4/8, "Skip to settlement", position `n/N`, a "This is a mock recording" / (once a real recording exists) "This really happened on BSV mainnet" badge. `?replay=mock-demo` → `REPLAY` badge.
- `tools/record.mjs` (a real-stream recorder: subscribes to WS + SSE → JSONL) — a skeleton in P1; used once there is an S1/S2 mainnet run.
