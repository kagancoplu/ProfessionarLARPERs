Every flow also runs offline on the wallet-toolbox mock chain with the real components; the test that exercises each type is listed with it.

## Not yet on mainnet

- Coop Rail (T11, T11b): the Base contract is not deployed and no live swap has run ([RAIL-POC.md](../RAIL-POC.md)).
- A second, independent coordinator and the public-edge rate limits (T-19) behind a public proxy: tested on the mock chain only.
- The web app's wallet flows with BSV Desktop on mainnet: tested end to end on the mock chain (`test/web.live-flows.mockchain.test.ts`); people joined mainnet pools with `participant-cli`.
